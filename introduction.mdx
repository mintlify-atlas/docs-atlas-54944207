# Welcome to SIGSAHO

**S.I.G.S.A.H.O.** (Sistema de Gestión de Operaciones Aeronáuticas) is a comprehensive **Aviation Operations Management System** designed to centralize, control, and optimize aeronautical operations. Built as a full-stack SaaS application, SIGSAHO empowers aviation teams to manage their entire operation from a single platform.

## What is SIGSAHO?

SIGSAHO is an enterprise-grade system that brings together:

- **Fleet Management** - Track aircraft status, maintenance schedules, and component lifecycles
- **Flight Operations** - Manage medical and operational transfers with real-time tracking
- **Crew Management** - Monitor personnel certifications, training, and compliance
- **Maintenance Control** - Schedule inspections, track service history, and manage parts inventory
- **Operational Intelligence** - Dashboard analytics and statistical insights for data-driven decisions

## Key Features

### Centralized Operations

All your aviation operations in one place - no more juggling spreadsheets, paper logs, and disconnected systems. SIGSAHO provides a single source of truth for your entire operation.

### Role-Based Access Control

Granular permission system ensures users only see what they need. From administrators to dispatchers, maintenance crews to training coordinators - everyone has their tailored workspace.


### Real-Time Data

Powered by TanStack Query for efficient server-state management, SIGSAHO keeps your data fresh with intelligent caching and background updates.

### Mobile-First Design

Responsive interface built with Tailwind CSS ensures seamless experience across desktop, tablet, and mobile devices - manage operations from anywhere.

## Architecture Highlights

### Feature-Sliced Design (FSD)

SIGSAHO's frontend follows Feature-Sliced Design architecture, organizing code by business domains rather than technical layers:

```text
src/features/
├── auth/              # Authentication & authorization
├── dashboard/         # Main operational dashboard
├── registerServices/  # Flight transfer management
├── despacho/          # Fleet dispatch & maintenance
├── controlAereo/      # Air traffic tools (METAR, W&B)
├── seguimiento/       # Personnel training & tracking
└── configuracion/     # System configuration (admin)
```

Each feature is self-contained with its own:
- **Data layer** - TypeScript types and Zod schemas
- **Service layer** - API communication hooks
- **ViewModel layer** - Business logic and state management  
- **View layer** - UI components and pages

<Note>
  This architecture ensures features remain isolated, testable, and maintainable as the system scales.
</Note>

### Security-First Authentication

SIGSAHO implements a zero-localStorage security model:

- **httpOnly cookies** - Tokens never exposed to JavaScript
- **XSS mitigation** - Session data stored server-side only
- **Automatic token refresh** - Seamless session management
- **Type-safe guards** - Runtime validation of user roles

```typescript
// Example: Protected route with role requirement
<RequireRole roles={[SystemRoles.DESPACHADOR, SystemRoles.ADMINISTRADOR]}>
  <AircraftDispatch />
</RequireRole>
```
