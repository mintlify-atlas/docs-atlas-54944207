## Endpoint

```
POST /auth/login
```

Authenticates a user using their username or email and password. On successful authentication, sets httpOnly cookies with access and refresh tokens.

<Note>
  **Rate Limiting:** This endpoint is limited to **5 attempts per 15 minutes per IP address** to prevent brute-force attacks.
</Note>

## Request Body

<ParamField body="identifier" type="string" required>
  Username or email address of the user
  - Minimum length: 3 characters
  - Maximum length: 255 characters
  - Case-insensitive for email addresses
</ParamField>

<ParamField body="password" type="string" required>
  User's password
  - Minimum length: 1 character
  - Maximum length: 255 characters
</ParamField>

<ResponseField name="message" type="string">

<ResponseField name="user" type="object">

        </ResponseField>

      Whether the user has login access to the system

  </Expandable>
</ResponseField>

### Cookies Set

On successful login, the following httpOnly cookies are automatically set:

| Cookie Name | Value | Expiry | Attributes |
|-------------|-------|--------|------------|
| `accessToken` | JWT access token | 15 minutes | httpOnly, secure (prod), sameSite=strict |
| `refreshToken` | JWT refresh token | 7 days | httpOnly, secure (prod), sameSite=strict |

## Request Example

<CodeGroup>
```bash cURL
curl -X POST https://api.sigsaho.com/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "identifier": "jperez",
    "password": "MySecure@Pass123"
  }'
```

```javascript JavaScript (Fetch)
const response = await fetch('https://api.sigsaho.com/auth/login', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  credentials: 'include', // Important: Include cookies
  body: JSON.stringify({
    identifier: 'jperez',
    password: 'MySecure@Pass123'
  })
});

const data = await response.json();
console.log(data.user);
```

```python Python (Requests)
import requests

url = "https://api.sigsaho.com/auth/login"
payload = {
    "identifier": "jperez",
    "password": "MySecure@Pass123"
}

response = requests.post(url, json=payload)
data = response.json()
print(data['user'])

# Cookies are automatically stored in the session
```
</CodeGroup>

## Error Codes

| Status Code | Description |
|-------------|-------------|
| 200 | Login successful, cookies set |
| 400 | Invalid request body or missing required fields |
| 401 | Invalid credentials (username/email or password incorrect) |
| 429 | Rate limit exceeded (too many login attempts) |

<Warning>
  **Security Best Practices:**
  - Never log or expose passwords in your application
  - Always use HTTPS in production to protect credentials in transit
  - Store tokens securely (the API uses httpOnly cookies for this)
  - Implement proper error handling without exposing sensitive information
</Warning>

## Implementation Details

The login endpoint performs the following operations:

1. **Validates** the request body against the login schema (src/schemas/auth.schema.ts:32)
2. **Authenticates** the user via AuthService.login() (src/controllers/auth.controller.ts:20)
3. **Generates** JWT access token (15 minutes expiry) and refresh token (7 days expiry)
4. **Sets** httpOnly cookies with appropriate security flags
5. **Returns** the user object with roles

<Info>
  The identifier field accepts both username and email for convenience. The system automatically determines which one is provided and performs the appropriate lookup.
</Info>
